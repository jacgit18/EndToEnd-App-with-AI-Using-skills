# ADR 0016 — CI provider

- **Status:** Accepted
- **Date:** 2026-09-10
- **Deciders:** the owner
- **Derived via:** `Architecture/tech-decision-walkthrough`, decision 14 (closeout audit,
  routine tier)

## Context

Solo project, repo expected on GitHub. The test plan wants unit + integration on every PR,
budget < 3 min, `alembic upgrade head` against a scratch DB, and E2E left to local pre-release
runs.

## Decision

**GitHub Actions.**

PR workflow:
1. `uv sync` (backend deps, cached).
2. Lint — `ruff check` + `ruff format --check`.
3. `pytest` — unit + integration, with a Postgres **service container**; `alembic upgrade head`
   against it first.
4. Frontend — `npm ci`, `tsc --noEmit`, `vitest run`, `vite build`.

Playwright is **not** in CI (no browser infra for the MVP, per the test plan) — run locally
before a release.

## Alternatives considered

- **GitLab CI** — only if the repo were on GitLab; it is not.
- **CircleCI / Buildkite / others** — another account and config dialect for zero benefit at
  this size.

## Consequences

- Free for a personal/public repo; nothing to self-host.
- Config lives in `.github/workflows/` — versioned with the code.
- Coverage % enforcement is deferred (`Testing/coverage-policy`, per the test plan).
- If the repo ever moves off GitHub, the workflow is ~50 lines to port.
